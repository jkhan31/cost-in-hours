# 🕓 Cost in Hours

A calm, privacy-focused web application that helps you make better purchasing decisions by converting prices into hours of work time.

## 🎯 What It Does

**Cost in Hours** transforms the way you think about purchases. Instead of just seeing a price tag, you'll see how many hours of your life you'd need to work to afford it. This shift in perspective helps you:

- **Pause before impulse purchases** by visualizing the time cost
- **Make informed decisions** about whether to buy now, wait, or skip
- **Track items you're considering** with a built-in waiting list
- **Set reminders** for future purchase decisions

## ✨ Features

- **Time-Based Cost Calculator**: Converts any price into hours based on your income (hourly, monthly, or yearly)
- **Flexible Work Hour Settings**: Customize calculations based on your actual work schedule
- **Waiting List**: Save items you want to reconsider later with optional reminders
- **Calendar Integration**: Export waiting items to your calendar (.ics format)
- **Dark Mode**: Comfortable viewing in any lighting condition
- **Privacy-First**: All data stored locally on your device - nothing sent to servers
- **PWA Support**: Install as a progressive web app for offline access

## 🚀 Quick Start

**Prerequisites:** Node.js

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Open your browser:**
   Navigate to `http://localhost:3000`

## 📦 Build for Production

```bash
npm run build
npm run preview
```

## 🔒 Privacy

This application:
- ✅ Does **not** require an account
- ✅ Does **not** collect personal information
- ✅ Stores all data **locally** in your browser
- ✅ Does **not** send data to any server
- ✅ Can be used **completely offline** (when installed as PWA)

## 📱 Usage Tips

1. **First Time Setup**: Enter your income type and amount for accurate calculations
2. **Adjust Work Hours**: Click "Adjust weekly work hours" if you work non-standard hours
3. **Save Items**: Use the "Wait" option to add items to your consideration list
4. **Set Reminders**: Choose a duration or specific date when saving items
5. **Export to Calendar**: Click the 📅 button to add reminders to your calendar app
